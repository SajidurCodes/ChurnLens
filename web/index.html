Customer profile

Use the source dataset’s first-nine-month aggregates. Subscription length is measured at the observation cutoff.

Input definitions

Usage is measured in seconds; subscription length is in months. Charge amount is an ordinal band, not a currency amount. Band 10 is retained because it occurs in the source data, although its documentation describes bands 0–9.

Age groups use the source’s ordered codes, from 1 (youngest) to 5 (oldest). Exact age boundaries are not established here. Enter whole numbers. Blank values are not treated as zero.

Model version

The decision uses the full-precision threshold returned by the API. Displayed percentages are rounded.

This is an offline benchmark predicting month-twelve churn status from earlier aggregates. Future-period performance has not been verified.

Probabilities are imperfect estimates. A review flag is not proof that a retention offer will work, and being below the threshold does not mean zero risk.

The threshold was selected under a 20% validation review-capacity assumption. It does not guarantee that capacity on new customers.
